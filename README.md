# 📊 Business Intelligence Report Generator

A desktop-based **Business Intelligence (BI) and Data Analysis application** developed using **Python**, **Pandas**, **Tkinter**, and **Matplotlib**. The application enables users to transform raw CSV/Excel datasets into meaningful business reports and visualizations through an intuitive graphical interface.

Designed for analysts and business users, the tool automates data summarization, KPI reporting, visualization, and export workflows without requiring SQL or programming knowledge.
---

## 🚀 Key Features

✅ Import CSV and Excel datasets

✅ Automatic dataset inspection

- Displays row count
- Displays column count
- Displays dataset headers

✅ Dynamic Report Builder

- Group By any categorical column
- Select numeric metric
- Perform aggregations

Supported Aggregations

- Sum
- Average
- Mean
- Count
- Median
- Maximum
- Minimum

✅ Interactive Data Visualization

Generate professional charts including

- 📊 Bar Chart
- 📈 Line Chart
- 📉 Column Chart
- 🥧 Pie Chart

✅ Export Functionality

- Export Report → Excel (.xlsx)
- Export Report → CSV (.csv)
- Export Charts → PNG

# ⭐ Why this Project?

Organizations often receive business data in CSV or Excel format that requires manual summarization and visualization.

This project streamlines that workflow by allowing users to quickly generate aggregated reports, visualize business trends, and export results in multiple formats through an easy-to-use desktop application. It demonstrates practical applications of Python in business intelligence and analytics.
